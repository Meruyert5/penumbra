# Repo-scoped UI skills

Installed from the [UI Skills catalog](https://www.ui-skills.com/skills) on 2026-11-12. Each folder contains the upstream `SKILL.md`; the skill IDs are prefixed with `ui-` so they do not collide with globally installed skills. Each skill keeps its upstream license; follow the source link for the original repository and terms.

OpenCode loads repo-scoped skills from this directory. Restart or reload the session to make the new IDs visible to the skill tool. The dashboard work cites the guidance directly from these files.

## How this set is used

- Motion and performance: `ui-animate`, `ui-animation-performance`, `ui-60fps-animation`, `ui-fixing-motion-performance`, `ui-accessible-animation`.
- Color and typography: `ui-better-colors`, `ui-oklch-skill`, `ui-better-typography`, `ui-typeset`.
- UI craft and interaction: `ui-emil-design-eng`, `ui-make-interfaces-feel-better`, `ui-better-ui`, `ui-better-accessibility`, `ui-interaction-design`.
- Structure and systems: `ui-better-interface`, `ui-create-design-md`, `ui-token-mapping`, `ui-codebase-design`.
- Verification: `ui-web-quality-audit`, `ui-interface-review`, `ui-break-ui`, `ui-playwright-cli`.
- Video and 3D: installed as reference for optional project assets. The dashboard stays dependency-free, so Three.js and video tooling are not added to the one-file build.
