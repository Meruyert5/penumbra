The run

A quiet baseline, then one loud hour.

Eleven hourly buckets. Three isolated events sit in the quiet hours; 167 matched events land in the 11:00 hour as the multi-stage scenario unfolds. The shape matters: a rule that fires on everything cannot discriminate.

Proof

Same seed. Same queue.

The lab needs Python 3.11 and Docker. Generation is deterministic, so the same commands produce the same 2,182 events, the same 44 detections, and this same page.

From zero to a reviewed queue

Swap the logsource map to point at real data streams when you have them. Until then, every event here is synthetic. The pipeline does not claim production precision from lab telemetry.
