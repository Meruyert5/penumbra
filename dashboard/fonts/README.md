# Embedded fonts

The dashboard embeds five latin-subset WOFF2 files so the published page stays
self-contained and works from `file://`:

- **Archivo** variable, weights 100-900.
  Copyright 2020 The Archivo Project Authors
  (https://github.com/Omnibus-Type/Archivo).
- **Space Mono** 400 and 700.
  Copyright 2016 The Space Mono Project Authors
  (https://github.com/googlefonts/spacemono).
- **Bodoni Moda** variable roman and italic, weights 400-900.
  Copyright 2020 The Bodoni Moda Project Authors
  (https://github.com/indestructible-type/Bodoni).

All three families are licensed under the SIL Open Font License, Version 1.1.
The full license text is in `OFL.txt`. The files were downloaded from Google
Fonts and are redistributed here unmodified.
