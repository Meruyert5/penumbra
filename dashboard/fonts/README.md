# Embedded fonts

The dashboard embeds five latin-subset WOFF2 files so the published page stays
self-contained and works from `file://`:

- **Bricolage Grotesque** variable, weights 200-800.
  Copyright 2022 The Bricolage Grotesque Project Authors
  (https://github.com/ateliertriay/bricolage).
- **DM Mono** 400 and 500.
  Copyright 2020 The DM Mono Project Authors
  (https://www.github.com/googlefonts/dm-mono).
- **Fraunces** variable roman and italic, weights 300-700.
  Copyright 2020 The Fraunces Project Authors
  (https://github.com/undercasetype/Fraunces).

All three families are licensed under the SIL Open Font License, Version 1.1.
The full license text is in `OFL.txt`. The files were downloaded from Google
Fonts and are redistributed here unmodified.
