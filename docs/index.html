06 · The proof

Run it yourself.

The lab needs Python 3.11 and Docker. The dashboard is one file with no build step and no external assets.

From zero to a reviewed queue.

Generation is deterministic. The same seed produces the same 2,182 events, so a reviewer can compare your output with theirs. Swap the logsource map to point at real data streams when you have them.

Every event in this report is synthetic. The pipeline does not claim production precision from lab telemetry.

signal-foundry / powershell
PS> python -m pipeline.labgen --scenario all --out lab/logs
PS> python -m pipeline.compile
PS> docker compose up -d
PS> python -m pipeline.ingest --reset
PS> python -m pipeline.detect --hours 24
PS> python -m pipeline.report
