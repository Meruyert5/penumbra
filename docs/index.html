06

Recurrence

Same seed. Same orbit.

The lab needs Python 3.11 and Docker. Generation is deterministic, so the same commands produce the same event field, the same detections, and this same page.

From zero to a reviewed queue

Swap the logsource map to point at real data streams when you have them. The dashboard run is synthetic; the separate replay band below is real. The pipeline does not claim production precision from lab telemetry.
