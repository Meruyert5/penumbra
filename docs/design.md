# Signal Foundry design system

This document records the interface decisions that govern the dashboard in
[`docs/index.html`](index.html). The source of truth is
[`dashboard/styles.css`](../dashboard/styles.css), [`dashboard/app.js`](../dashboard/app.js),
and [`dashboard/template.html`](../dashboard/template.html).

## Identity

Signal Foundry is a forensic case file wired to a SOC console. Paper carries the
evidence, the dark rail carries the instruments, and the signal palette marks
live state. The dashboard should feel authored by an analyst, not generated by a
component library.

## Principles

1. **Evidence before decoration.** Every number traces to an event, a detection,
   or a coverage rule. Decorative marks never replace the reading.
2. **Signal over noise.** The page carries several loud hours, a quiet baseline,
   one queue, and three cases. Nothing else earns space.
3. **Paper and console are one system.** The light theme is the case file; the
   night theme is the same file on a dark desk. The run ticket stays paper in
   both.
4. **Motion is a live instrument.** Motion shows scanning, replay, and state.
   It pauses offscreen and disappears under reduced motion.
5. **The dashboard is the deliverable.** One self-contained HTML file, no CDN,
   no framework, no build step, no external font request.

### Roles

- **Case red (`--rust`)** marks the brand, the primary action, case tabs, and
  critical classification. It is not used for live state.
- **Signal cyan (`--signal`)** marks live state: the rail waveform, live dots,
  the chart scan, the crosshair, the peak pulse, and the pipeline signal dot.
- **Forest teal (`--forest`)** marks coverage, verdicts, technology tags, and
  valid evidence.
- **Ochre** is reserved for the high/medium severity family and paper accents.
- **Paper neutrals are warm and light.** Background, surface, rules, and muted
  text share one paper scale, so cards and coverage tiles sit on the page
  instead of reading grey-green.
- **Stat numbers share one hierarchy.** On the run stat line, detections and
  execution errors use the primary ink. Correlations, critical detections, and
  priority coverage each keep one accent. The line appears once, on the run
  ticket, and the cover does not repeat it.
- **One accent per rule.** Section rules use one accent or a neutral line each.
  The watch floor has no rule above its status band; the band itself is a tinted
  paper strip. The run ticket band is the only four-color gradient.
- **Coverage tiles use `--tile`, a toned-down white.** It is lighter than the
  page but not a bright white, so a low-priority tile such as `T1595.002` reads
  as paper rather than grey.
- **The watch floor inspector is a near-surface panel.** It uses a light mix of
  `--surface` and `--surface-2`, and stretches to the full height of the queue,
  so the right side stays close to the queue without leaving a blank gap before
  the host lanes.
- **The sheet has a folded corner.** A dog-ear of `clamp(46px, 6.2vw, 104px)`
  sits at the top right of the paper theme. It uses a lit paper-back gradient, a
  crease shadow, and an inset run line so the fold never covers the text. The
  flap scales and rotates out of the corner with a small overshoot while the
  crease shadow fades in. The animation uses transform and opacity only, and
  settles to its final state under reduced motion or static capture.
- **Night ticket paper** is `#eef1ea` with `#121b1c` ink. It is a physical
  receipt on the dark desk, not a dark panel.

## Typography

- **Display and body:** Bricolage Grotesque variable, weights 200-800, embedded
  as WOFF2.
- **Data and labels:** DM Mono 400 and 500 only. The design never requests
  synthesized 600 or 700 weights. Weight 500 is the strongest mono label.
- Body: `1rem/1.62`, with antialiasing on the root.
- Display: `clamp(48px, 6.8vw, 104px)` at `0.92` line-height and `-0.045em`
  tracking.
- Chapter titles: `clamp(30px, 3.8vw, 50px)` at `1.02`.
- Ledes cap at 54ch or 68ch. Case summaries cap at 68ch.
- Headings use `text-wrap: balance`; prose uses `text-wrap: pretty`.
- Numbers in counters, tables, tickets, and the chart use
  `font-variant-numeric: tabular-nums`.
- Buttons, badges, and data labels use uppercase mono with deliberate
  letter-spacing. Body copy stays in natural case.
- Inputs use 16px on mobile to prevent iOS zoom, and 44px minimum height.
- Micro labels never drop below 9px. Paper texture is baked into the background
  at low contrast: a broad mottle, a directional fiber layer, fine grain, and a
  soft edge vignette. The night theme uses the same three layers with a screen
  blend, so both themes share one material. Text-bearing elements settle to
  `transform: none` instead of scale animations.
- The line-height in `@font-face` and the UI is unitless. Type roles are fixed;
  avoid introducing one-off sizes.

## Shape, space, and elevation

- Radii: `4px` micro, `8px` control, `12px` button, `16px` panel, `22px`
  overlay.
- The run ticket is square. Severity stamps use `3px`. Paper strips stay square.
- Spacing follows a 4px base with 8, 12, 16, 24, 32, 48, 64, 96, 112 steps.
- Borders carry structure. Shadows carry elevation. Paper uses a light layered
  shadow; night uses a deeper shadow plus a 1px inset top highlight.
- Night panels receive a very low white gradient at the top so they separate
  from the page without a colored fill.
- Focus rings are 2px with 3px offset. Primary and active controls switch the
  ring to `currentColor` so it stays visible on the red or cyan fill.
- Hover lift is limited to hover-capable pointers. Touch gets a stable selected
  state.

## Motion

### Interaction motion

| Role | Value |
|---|---|
| Fast feedback | 150-180ms, `cubic-bezier(0.16, 1, 0.3, 1)` |
| Standard state | 200-240ms |
| Panel or modal enter | 260-320ms |
| Section reveal | 700ms |
| Press scale | `0.96` over 150ms |

Only `transform` and `opacity` are animated for interactive feedback. Layout
properties are not transitioned. `transition: all` is not used.

### Ambient motion

These loops run while the page is open. They pause or disappear under reduced
motion.

| Element | Loop |
|---|---|
| Chart scan | 6.5s linear sweep, only while the plate is visible |
| Chart bars | 8s automatic replay, only while visible |
| Peak pulse | 3.4s ping |
| Quiet event dots | 3.6s pulse |
| Coverage gauge | 7s wave, staggered 45ms per tick |
| Pipeline signal dot | 8s travel, transform only |
| Case tab | 6s opacity pulse |
| Rail waveform | 5.5s dash drift |
| Live dots | 2.6s ping |

The theme toggle uses the View Transitions API. Transitions are suppressed for
the swap so the crossfade does not smear individual properties.

Under `prefers-reduced-motion: reduce`, movement, scale, blur, and the ambient
loops are removed. The page remains fully readable and operable.

## Data semantics

- The chart counts **matched events** by hour.
- The watch floor groups those events into **detections** and **correlations**.
- The cover and fact line report detections, correlations, critical detections,
  coverage, and execution errors. They never reuse the word "matches" for two
  different units.
- The active-hour filter uses each detection's first/last seen span, so a quiet
  hour with one event still returns the detection that spans it.
- Coverage counts priority techniques only. All 45 are covered. The gaps view remains as a regression check.

## Instruments

- **Live scope.** The cover carries a dark instrument plate, separate from the
  paper sheet. It draws the hourly totals as a trace on a canvas, with a scan
  slit that pings when a bucket crosses 35% of the peak. It runs only while on
  screen, and under reduced motion or static capture it draws once.
- **Envelope.** The chart's smoothed envelope is clamped to each segment, so it
  never dips below the zero baseline. It draws once per replay.
- **Method plate.** Each stage shows an icon and the artifact it writes, such as
  `rules/compiled/rules.json`, so the chain of custody names real files.
- **Syntax.** EQL and KQL use a small token pass, escaped before insertion.

## Watch floor

The queue is a split workspace above 980px: detections and correlations on the
left, a fixed evidence inspector on the right. Selecting a row updates the
inspector without opening a drawer, so the queue and the evidence stay in view
together. Below 980px the inspector hides and rows fall back to inline drawers.

Two panels sit under the workspace. **Host lanes** plot every detection against
the same 03:00–13:00 window as the run chart, with severity-colored marks and one
lane per host. The **coincidence strip** lists the correlation alerts with their
counts; selecting one switches the queue to the correlation tab and opens its
record. Both are built from the same payload as the chart, so the console cannot
drift from the report.

The watch floor status strip carries the window end, detection count, coincidence
count, and execution errors. In the paper theme it is a tinted paper strip. In
the night theme it becomes the console's darkest surface.

## Accessibility

- Skip link to the watch floor.
- One visible focus ring system, including on filled primary buttons.
- SVG chart is focusable and supports arrow-key hour selection.
- Watch floor rows support `J`/`K` and `Enter`; `/` focuses search; `T` switches
  theme; `G` starts the tour; `?` opens the shortcut panel.
- Command palette, keyboard panel, case file, and guided tour trap focus and
  return focus on close.
- Background scroll locks while a palette, case file, or shortcut panel is open.
  The scrollbar gutter is reserved to avoid layout shift.
- Dialogs set `aria-hidden` when closed. Tabs expose `aria-controls`. Severity
  chips and the gaps toggle expose `aria-pressed`.
- Search, host, and sort controls have labels. Live readouts use
  `aria-live="polite"`.
- Tap targets: primary actions 48px, fields 44px on mobile, filters 32px on
  mobile, secondary mini buttons 24-30px. The dense matrix is the only exception,
  and its tiles remain large enough to tap.
- The night ticket keeps AA contrast for every label.

## Verification

```powershell
node --check dashboard/app.js
.\.venv\Scripts\python.exe -m pipeline.report
.\.venv\Scripts\python.exe -m pytest -q
```

Reproducible screenshots:

```text
?theme=light&static=1
?theme=dark&static=1
```

`static=1` disables animation and count-up, so documentation images show final
numbers and the paper ticket without waiting for the entrance to finish.

The dashboard has no external requests. All CSS, JavaScript, fonts, and data are
inlined in `docs/index.html`, so it opens from disk and loads the same way on
Pages. To measure it, run Lighthouse in Chrome DevTools against the local file or
the Pages URL. Scores depend on the Chrome version and the machine, so this repo
does not publish a fixed number.
